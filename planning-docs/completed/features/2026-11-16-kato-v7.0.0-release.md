## Open follow-ups (none part of this release; SPRINT_BACKLOG items 13-22)
13. Deploy 7.0.0 and recount existing nodes (`scripts/recount_pattern_frequencies.py` from the checkout against the stack's Redis, `--dry-run` first, while no node is learning or purging; not in the image). Pending the user's approval; no deploy plan is agreed.
14. `future_potentials` has no "ends here" share: when the pattern that best explains the STM has no future, a weak candidate can get probability 1.0. Documented, with the `good_odds` of the proposing predictions as the check.
15. Affinity not measured with the new potential; for an STM of two or more symbols only the STM's symbols get an affinity weight, so the `weighted_*` metrics overstate the match.
16. With `fuzzy_token_threshold` above 0, `matches` ignores position and multiplicity, so evidence and confidence can exceed 1. Open question: does anything use that path?
17. `normalized_entropy` / `global_normalized_entropy`: values stored by finalize-training go stale when the node learns afterwards; the second is not an entropy and can exceed 1. Open question: keep, redefine or retire.
18. Emotives: each key is averaged over only the window entries that carry it. Open question: intended?
19. A potential pruned to four or five terms has not been fitted or tested.
20. The cost of scoring every candidate has not been measured on the live instance's nodes.
21. `examples/python-client.py` has two lint findings (F401, F841) outside CI's lint scope.
22. Delete merged remote branches `feat/prediction-metrics` and `docs/recall-threshold-observed-share` (awaiting user).
